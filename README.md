# Personal Portfolio Website - Nicho Kurnia Adi Nugroho

Website portofolio personal modern, elegan, dan profesional bergaya *clean minimalist* (ala Apple/modern agency) yang dirancang untuk menampilkan profil, keahlian, pengalaman kerja, sertifikasi, serta proyek-proyek digital.

## 🚀 Fitur Utama
- **White Modern / Clean Minimalist Design**: Tampilan estetis dengan dominasi warna bersih, card ber-radius elegan, serta soft shadow.
- **Dark / Light Mode Toggle**: Fitur pengubah tema terang/gelap yang dapat disesuaikan oleh pengunjung.
- **Background Music Player**: Pemutar musik latar mengapung interaktif dengan indikator animasi gelombang suara.
- **Custom Cursor**: Kursor kustom modern yang interaktif pada perangkat desktop.
- **Scroll Progress Bar**: Indikator progres gulir halaman di bagian paling atas layar.
- **Interactive Animations**: Efek animasi teks berjalan (*typing effect*), counter statistik, *glitch effect* pada badge pengalaman, serta transisi *smooth scroll*.
- **Fully Responsive**: Dioptimalkan secara sempurna untuk perangkat Desktop, Tablet, dan Smartphone.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5** (Semantic Markup)
- **CSS3** (Custom Properties / CSS Variables, Flexbox, Grid)
- **JavaScript Vanilla** (ES6+)
- **Bootstrap 5** (Layout & Utility Framework)
- **Font Awesome 6** (Icons)
- **Google Fonts** (Plus Jakarta Sans)
